# 強姦01後書き
これは作者のドロがこうされたいというファンタジーで、小動物だとかは、ヒロインを自分自身だと感じるために、実際に言われた評価言葉をいれている。でも主観すぎないように、作品として読めるように、三人称にしている。

作中で膣内射精してるが、堕胎は書けないのでこの続きは無しかな。
私はいつもキャラに憑依して書くようにしてて、このOなら腹を蹴って堕胎させるかもしれないが、私はそこまでの暴力性をエミュできない。怖くて無理。かといってOはかわいそうだという人物ではない。
書くとしたら新キャラがドロを引き取って子供もろとも優しく接するか、ドロが胎児を守るために手段を選ばなくなるか。（殺害はしないが目潰しぐらいはやる）

影響を受けたのは
時計じかけのオレンジ、ファニーゲーム、ゴーン・ガール

# 監禁01後書き

実録からスタートしてなにか書きたいと思って気楽に始めた。最初の１行が実録で、そのあとはOを配置したら勝手に進行した。Oというのは私の頭の中にいるサイコパス戦闘員
かゆみやぐるぐるは私の実際の症状だが、私の双極性障害による閉塞感が監禁のイメージとむすびついたのかもしれない。

影響を受けたのは
時計じかけのオレンジ、ルーム

# 絞殺01後書き

Oの本質は退屈であるという解釈からきてる。

殺されたいドロ、という本題は最初の一段にすぎなくて、凝ったのは周囲の反応と、生殖と殺害が同時である矛盾。
生々しく露骨なセリフは、口先だけで言ってる性欲ではなく、「あの」射精衝動なんだという説得力を持たせるため。だがポルノ目的ではないので地の文を抑えめにして調整が難しかった

雰囲気づくりがんばった。
抽象と具体のバランスが気に入っている

畢竟～の部分は利己的な遺伝子の細胞の雌雄のパートを読んだことが影響している
